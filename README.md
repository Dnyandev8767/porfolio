## 🌟 Overview

This portfolio showcases the technical skills, featured software projects, professional experience, and academic journey of **Daphal Dnyandev**, a Full Stack Web Developer and Bachelor of Computer Science (BCS) student from Sambhajinagar, Maharashtra, India.

Built from the ground up without heavy third-party CSS or JS frameworks, it delivers **sub-second page load times**, buttery-smooth 60 FPS animations, and high visual aesthetics adhering to modern web design standards.

---

## ✨ Key Features

- 🌌 **Interactive 3D WebGL Background**: Three.js-powered canvas featuring **3 switchable visual modes** (Wave Grid, Hyperspeed Warp, Floating Crystals) with interactive mouse tracking and ambient 2D particle glow.
- 🌓 **Dual Theme Engine (Dark & Light Mode)**: Smooth color transition engine with persistent `localStorage` memory and automatic synchronization with 3D canvas materials.
- 🎴 **3D Perspective Tilt Hero Card**: Multi-layered mouse-reactive tilt effect with dynamic glare reflection and floating live status badges.
- ⌨️ **Dynamic Typing Headline**: Smooth typewriter effect highlighting developer specializations and technical domains.
- 📊 **Animated Metric Counters**: IntersectionObserver-powered counter displaying 25+ completed projects, 1,500+ commits, and client satisfaction metrics.
- 🎯 **Filterable Technical Skills Matrix**: Category filter tabs (*Frontend*, *Backend & APIs*, *Databases & Cloud*, *Tools & DevOps*) with animated percentage progress bars and additional tech badges.
- 💼 **Interactive Projects Showcase**: Categorized portfolio cards with hover zoom, quick action links, and comprehensive **in-depth modal case study dialogs**.
- ⏳ **Dual-Mode Journey Timeline**: Dynamic switcher toggling between professional work experience and academic milestones / industry certifications.
- 💬 **Peer Endorsements & Testimonials**: Glassmorphic recommendation cards showcasing feedback from engineering leads and collaborators.
- 📝 **Real-Time Validated Contact Form**: Comprehensive client-side form validation with regex patterns, live character counter, accessibility status icons, and animated toast feedback.
- 📄 **Curriculum Vitae / Resume Viewer**: Built-in modal resume preview with one-click print / PDF export capability.
- ⚡ **Navigation & Micro-Interactions**: Reading progress bar, magnetic social icons, audio chime feedback, active link spy, and an SVG circular progress back-to-top button.

## 🛠️ Tech Stack & Architecture

### Core Technologies
- **Markup**: Semantic [HTML5](https://developer.mozilla.org/en-US/docs/Web/HTML) (SEO optimized, Open Graph tags, schema structure)
- **Styling**: Modern [CSS3](https://developer.mozilla.org/en-US/docs/Web/CSS) (Vanilla CSS, Custom Properties / Tokens, CSS Grid, Flexbox, Glassmorphism, Micro-animations)
- **Logic**: Modern [JavaScript ES6+](https://developer.mozilla.org/en-US/docs/Web/JavaScript) (Modular architecture, Event Listeners, IntersectionObserver, Web Audio API, Canvas APIs)
- **3D Graphics**: [Three.js](https://threejs.org/) (r128) WebGL Renderer, Particle Geometry & Mesh Shaders
- **Icons & Typography**: [Font Awesome 6.5.1](https://fontawesome.com/), Google Fonts (*Inter*, *Outfit*, *Fira Code*)

### Architecture Principles
- **Zero Heavy Framework Bloat**: No React, Vue, or bulky bundlers required to run—native performance out-of-the-box.
- **Mobile-First Responsive Design**: Optimized across mobile (320px+), tablet, desktop, and 4K ultra-wide screens.
- **Accessibility & SEO**: WCAG 2.1 AA accessible contrast ratios, descriptive ARIA attributes, semantic headings, and meta tags.

## 🚀 Quick Start / Local Setup

No node module installations or build steps are required! You can run this project locally in seconds:

### Option 1: Direct File Open
Simply double-click [`index.html`](index.html) or open it directly in any modern browser (Chrome, Edge, Firefox, Safari).

### Option 2: Using VS Code Live Server
1. Clone the repository:
   ```bash
   git clone https://github.com/Dnyandev8767/porfolio.git
   cd porfolio
   ```
2. Open the directory in VS Code:
   ```bash
   code .
   ```
3. Right-click [`index.html`](index.html) and select **"Open with Live Server"**.

### Option 3: Using Python HTTP Server
```bash
# Python 3
python3 -m http.server 8080
```
Then navigate to `http://localhost:8080` in your web browser.

### Option 4: Using Node.js / npx
```bash
npx serve .
```
